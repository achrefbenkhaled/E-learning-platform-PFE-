# PFE VE Finale

This project contains several components for an E-Learning platform and an Anti-Cheat system.

## 📂 Project Structure

- **`learnhub-elearning/`**: The main e-learning platform.
  - `backend/`: Node.js/Express API.
  - `frontend/`: React application.
- **`anti cheat/`**: Security tools for exams.
  - `react-frontend/`: Anti-cheat dashboard.
  - `wpf-app/`: Windows desktop application for secure exams.
  - `main.py`: Python backend/logic for anti-cheat.

## 🚀 Getting Started

### Prerequisites
- Node.js & npm
- Python 3.x
- .NET SDK (for WPF app)

### Installation
1. Clone the repository.
2. Install dependencies for each sub-project:
   ```bash
   # Example for frontend
   cd learnhub-elearning/frontend
   npm install
   ```
